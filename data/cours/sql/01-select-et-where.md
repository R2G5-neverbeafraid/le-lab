## SELECT et WHERE

Une base de données range les informations dans des **tables** (lignes et colonnes). Ici, la base de Peer-Learning a trois tables : `etudiants`, `tuteurs` et `seances`.

`SELECT colonnes FROM table WHERE condition` lit des lignes. `*` veut dire toutes les colonnes. Les textes vont entre **apostrophes** : `WHERE promo = 'L1'`. On combine avec `AND` / `OR`.
