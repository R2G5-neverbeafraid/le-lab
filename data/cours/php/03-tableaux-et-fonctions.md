## Tableaux et fonctions

Deux sortes de tableaux :

- indexé : `$notes = [12, 15, 9];` → `$notes[0]`
- associatif (comme un dictionnaire Python) : `$t = ["nom" => "Prisca", "matiere" => "Python"];` → `$t["nom"]`

Fonctions utiles : `count()`, `array_sum()`, `in_array()`, `strtoupper()`. On écrit les siennes avec `function nom($param) { return ...; }`.
