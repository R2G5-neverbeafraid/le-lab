## Syntaxe et variables

PHP s'exécute sur le **serveur**, avant que la page arrive dans le navigateur. Le visiteur ne voit jamais ton code PHP, seulement le HTML qu'il produit. Pour pratiquer chez toi : installe **XAMPP**, ou lance `php -S localhost:8000` dans ton dossier.

Le code se place entre `<?php` et `?>`. Les variables commencent toujours par `$`. Chaque instruction finit par `;`.

On colle des textes avec le **point** `.` (pas le +). Entre guillemets doubles, les variables sont remplacées : `"Salut $nom"`. Entre apostrophes, non.
