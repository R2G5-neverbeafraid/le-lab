## Fonctions et conditions

Deux façons d'écrire une fonction :

```
function double(x) { return x * 2; }
var triple = (x) => x * 3;
```

Pour comparer, utilise toujours `===` (même valeur et même type). `==` fait des conversions surprenantes : `"0" == 0` est vrai.

Les blocs `if / else if / else` sont délimités par des accolades.
