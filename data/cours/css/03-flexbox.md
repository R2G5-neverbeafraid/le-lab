## Flexbox

Flexbox aligne des éléments sur **une ligne** (ou une colonne). On l'active sur le **parent** : `display: flex`.

- `justify-content` : répartition sur l'axe principal (`space-between`, `center`…)
- `align-items` : alignement sur l'axe perpendiculaire (`center` pour centrer verticalement)
- `gap` : espace entre les enfants
- `flex-direction: column` pour empiler
