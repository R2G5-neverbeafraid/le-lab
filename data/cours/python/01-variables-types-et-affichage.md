## Variables, types et affichage

Une **variable** est une étiquette posée sur une valeur. Python devine le type tout seul :

- `int` : nombre entier, `42`
- `float` : nombre à virgule, `12.5`
- `str` : texte, `"RG"`
- `bool` : `True` ou `False`

Pour mélanger texte et variables, la **f-string** est l'outil le plus pratique : on met un `f` devant les guillemets et les variables entre accolades. Pour convertir : `int("12")`, `str(5)`, `float("3.5")`.

Attention aux trois divisions : `/` donne toujours un float, `//` la division entière, `%` le reste.
